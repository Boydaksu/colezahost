# UI Constitution

- PHP SSR + component system + progressive JS; production Node runtime not required.
- Admin dense/operational; Client simple/guided; same Core, separate experience.
- UI never performs authoritative pricing/tax/business calculations.
- Small action=modal, contextual detail=drawer, complex workflow=page.
- Critical/destructive actions show context/reason and may require typed confirmation/step-up.
- Design tokens and Core component library; arbitrary global module CSS/JS injection forbidden.
- Light/Dark/System, density, keyboard navigation, Ctrl+K, DataTable/saved views foundations.
- Accessibility from start: focus, labels/ARIA, contrast, reduced motion, no color-only status.
- Error UX: admin actionable technical detail; client simplified message + reference code.
