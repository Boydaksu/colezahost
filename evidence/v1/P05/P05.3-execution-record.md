## 1. Components Implemented
- `Coleza\Domain\Finance\Currency\Currency`: Entity handling ISO 4217 currency specifications, symbols, minor-unit formatting, active status, and default currency rules.
- `Coleza\Domain\Finance\Fx\FxRateProviderInterface`: Pluggable abstraction contract for exchange rate data providers.
- `Coleza\Domain\Finance\Fx\StaticFxRateProvider`: In-memory deterministic FX provider for offline operations, testing, and reciprocal rate calculations.
- `Coleza\Domain\Finance\Fx\FxSnapshot`: Immutable historical snapshot entity ensuring past invoices/transactions are never corrupted by future rate changes, with bidirectional currency conversion methods.
- `Coleza\Domain\Finance\Currency\CurrencyService`: Management service for currency registers, single-default enforcement, snapshot capturing, and historical snapshot queries.
