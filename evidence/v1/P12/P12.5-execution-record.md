## 1. Subphase Scope & Objective
Orchestrate end-to-end domain lifecycle operations between the catalog, local domain asset entities, timeline audit trail, and remote registrar adapters:
- **Availability Flow:**
  - `DomainRegistrarService::checkAvailability` validating domain syntax, catalog TLD enablement, registrar adapter availability check, and automated price resolution from TLD catalog pricing tiers.
  - `DomainRegistrarService::bulkCheckAvailability` for batch checks.
- **Registration Flow:**
  - `DomainRegistrarService::registerDomain` validating `pending_registration` state, compiling `DomainRegistrationCommand` with ICANN contact profiles and nameservers, executing remote registrar order, transitioning domain state to `active`, recording remote transaction IDs and expiration dates, and writing chronological timeline audit events (`registrar_register_success` / `registrar_register_failed`).
- **Renewal Flow:**
  - `DomainRegistrarService::renewDomain` validating domain operability, dispatching multi-year `DomainRenewalCommand` to registrar, advancing expiration and next due dates, and recording audit timeline logs.
- **Transfer Flow:**
  - `DomainRegistrarService::transferDomain` validating required EPP authorization code, dispatching `DomainTransferCommand`, updating local state to `pending_transfer`, and logging timeline events.
- **Nameservers Flow:**
  - `DomainRegistrarService::updateNameservers` validating hostnames, updating remote registrar, syncing local domain entity nameservers, and recording audit logs.
- **Registrar Lock Flow:**
  - `DomainRegistrarService::setRegistrarLock` toggling remote transfer lock and syncing local `is_locked` state.
- **EPP Code Flow:**
  - `DomainRegistrarService::retrieveEppCode` fetching remote auth codes from registrar and recording audit timeline.
- **Contact Management & Sync:**
  - `DomainRegistrarService::syncContactsToRegistrar` pushing ICANN contact profiles to registrar.
  - `DomainRegistrarService::syncDomainFromRegistrar` pulling remote nameservers and lock state into the local domain entity.
- **Lifecycle State Machine Transitions:**
  - Extended `DomainStateMachine` to support transfer lifecycle (`active -> pending_transfer`, `pending_registration -> pending_transfer`, and `pending_transfer -> transferred_out`).
