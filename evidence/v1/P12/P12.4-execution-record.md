## 1. Subphase Scope & Objective
Select and implement the production domain registrar adapter conforming to `RegistrarProviderInterface`, ensuring full lifecycle domain operations, automated error handling, sandboxing, and Vault secret protection:
- **Provider Selection:**
  - Selected **NameSilo** as the primary production domain registrar adapter due to its API-first design, comprehensive ICANN feature coverage, bundled WHOIS privacy, sandboxing capabilities, and rock-solid REST/JSON endpoints.
- **Production Adapter Implementation (`NameSiloRegistrarAdapter`):**
  - Implements `RegistrarProviderInterface` with full support for:
    - Availability checks (`checkRegisterAvailability`) parsing both JSON and XML payload formats.
    - Domain registration (`registerDomain`) with multi-year periods, nameservers, and WHOIS privacy flags.
    - Domain renewal (`renewDomain`).
    - Domain transfer (`transferDomain`) with EPP authorization codes.
    - Nameserver query and modification (`getDomainInfo`, `domainChangeNameServers`).
    - Registrar transfer lock control (`domainLock`, `domainUnlock`).
    - EPP/Auth code retrieval (`retrieveAuthCode`).
    - ICANN contact profile mapping and updates (`getDomainInfo`, `domainUpdateContacts`).
  - Supports dual-mode transport: injectable HTTP callable for deterministic testing, with native PHP stream context fallback for zero-dependency shared-host production compatibility.
  - Automatically selects sandbox endpoint (`https://sandbox.namesilo.com/api`) or production endpoint (`https://www.namesilo.com/api`), with custom proxy override support.
  - Automatic secret scrub: thoroughly sanitizes API keys and secrets with `••••••••` from raw payloads, URLs, and debug structures.
- **Registrar Adapter Factory (`RegistrarAdapterFactory`):**
  - Resolves registrar configuration and instantiates the chosen provider adapter with client injection support.
