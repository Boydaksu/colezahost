## 1. Subphase Scope & Objective
Establish core domain asset entities, ICANN contact profile standards, lifecycle state machine transitions, administrative domain controls, and chronological timeline event logging:
- **Domain Lifecycle State Machine:**
  - `DomainStateMachine` specifying canonical ICANN lifecycle states: `pending_registration`, `active`, `pending_transfer`, `expired`, `grace`, `redemption`, `cancelled`, and `transferred_out`.
  - State transition matrix preventing illegal state bypasses (e.g. cancelled -> active or pending_registration -> redemption).
  - Helper classification queries: `isOperable()` (active, grace), `isPending()` (pending_registration, pending_transfer), and `isTerminal()` (cancelled, transferred_out).
- **ICANN Contact Profiles:**
  - `DomainContact` model implementing standard four-contact roles: `registrant`, `admin`, `tech`, and `billing`.
  - Captures structured names, organization, email, E.164 phone, postal address lines, city, state, postal code, ISO 3166-1 alpha-2 country code, and custom metadata fields.
  - Storage table `domain_contacts` with `(domain_id, contact_type)` unique constraint for atomic profile upserts.
- **Domain Entity & Administrative Controls:**
  - `Domain` model representing registered domain asset:
    - SLD, TLD, active state, registration period years.
    - Dates: `registration_date`, `expiry_date`, `next_due_date`.
    - Helper queries: `daysUntilExpiry()` and `isExpired()` relative to simulated reference dates.
    - Control flags: `is_locked` (registrar transfer lock), `whois_privacy` (ID protection), `dns_management`, `email_forwarding`, and `auto_renew`.
    - Nameservers: array of up to 5 nameserver hostnames.
    - Security: `epp_code` authorization string with safe masking in array exports (`••••••••`).
- **Domain Audit Timeline:**
  - `DomainTimelineEvent` and storage table `domain_timeline_events` recording complete chronological audit logs for every domain event (`created`, `activated`, `renewed`, `locked`, `unlocked`, `whois_privacy_toggled`, `auto_renew_toggled`, `nameservers_updated`, `contacts_updated`, `status_changed`).
  - Stores actor identity (`actor_id`, `actor_type`: user, admin, system, automation) and JSON payload details.
- **Domain Service Coordinator:**
  - `DomainService` orchestrating domain lifecycle:
    - Domain validation via `DomainCatalogService`.
    - Activation setting registration and expiration dates.
    - Multi-year renewal extending expiration and next due dates.
    - Nameserver modifications with hostname validation.
    - Registrar lock toggles, WHOIS privacy toggles, and auto-renew configuration.
    - Contact profile upserts and retrieval.
