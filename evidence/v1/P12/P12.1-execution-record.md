## 1. Subphase Scope & Objective
Establish foundational domain vertical architecture, TLD catalog management, registration policies, multi-year and multi-operation pricing matrices, and domain label validation:
- **TLD Entity & Catalog:**
  - `Tld` model managing top-level domain specifications: normalized extension (leading dot, lowercase), active status, default registrar adapter mapping, duration limits (`minYears`, `maxYears`), IDN capability, EPP auth code requirements, WHOIS privacy eligibility, DNS management, email forwarding, grace period, redemption period, and custom schema requirements (e.g. `.com.tr` TCKN/VKN).
  - Storage table `domain_tlds` with unique extension index and JSON serialization for custom attributes.
- **Multi-Year & Multi-Operation Pricing:**
  - `TldPricing` model supporting domain operations: `register`, `renew`, `transfer`, `restore`.
  - Storage table `domain_tld_pricing` indexed by `(tld_id, operation, years, currency_code)`.
  - Multi-year calculation engine (`calculateRegistrationPrice`, `calculateRenewalPrice`, `calculateTransferPrice`, `calculateRestorePrice`):
    - Supports explicit promotional/discounted multi-year rates (e.g. 2-year deal).
    - Falls back to linear 1-year multiplication when explicit multi-year rows are not specified.
    - Gracefully defaults renewal and transfer prices to 1-year registration base rates when omitted.
- **Domain Syntax & Policy Validation:**
  - `TldPolicy` enforcing ICANN/RFC and TLD-specific rules:
    - Overall length <= 253 characters.
    - Second-level domain (SLD) label length 1..63 characters.
    - Hyphen rules: rejects leading/trailing hyphens; rejects consecutive hyphens at positions 3-4 (unless IDN punycode prefix `xn--`).
    - IDN restriction: rejects internationalized characters / punycode on TLDs where `is_idn_supported = false`.
    - Term validation: rejects registration or renewal requests outside supported `[min_years, max_years]` boundaries.
    - Special TLD requirements: enforces required custom attributes (e.g. `.com.tr` citizen/tax identification).
  - `DomainValidationResult` providing structured pass/fail decisions and descriptive validation errors.
- **Multi-Part TLD Domain Splitting:**
  - `splitDomain` intelligently identifies compound extensions (`.com.tr`, `.co.uk`, `.org.tr`) over single-level extensions, ensuring accurate SLD and TLD resolution.

## 4. Architectural Rules Audit
- **Strict typing:** `declare(strict_types=1);` enforced in all domain catalog files.
- **Bounded context boundaries:** The Domains domain operates independently with dedicated tables (`domain_tlds`, `domain_tld_pricing`) and domain service APIs.
- **Precision:** Prices and costs stored in integer minor units (cents/kuruş) to prevent floating-point discrepancies.
