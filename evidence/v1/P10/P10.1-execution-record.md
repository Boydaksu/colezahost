## 1. Components Implemented
- `Coleza\Domain\Providers\Cpanel\CpanelConfiguration`:
  - Enforces valid hostname, username, port (defaulting to 2087 SSL / 2086 non-SSL), and credential provision.
  - Factory `fromServerConnection(ServerConnectionDto)` automatically parses WHM username and auth credentials (`api_token`, `access_hash`, `password`).
  - Strict security masking: `getMaskedSecret()`, `toSafeArray()`, and `__debugInfo()` prevent plaintext credential leakage in logs or dumps.
- `Coleza\Domain\Providers\Cpanel\CpanelHttpTransportInterface`:
  - Abstract HTTP contract returning structured status code, response body, latency, and headers.
- `Coleza\Domain\Providers\Cpanel\CpanelMemoryTransport`:
  - In-memory mock transport for offline, deterministic, network-free unit test execution and CI environments.
  - Supports staged mock responses by WHM function/pattern, fallback defaults, and full request recording.
- `Coleza\Domain\Providers\Cpanel\CpanelCurlTransport`:
  - Production pure-PHP `curl_*` transport for shared-hosting baseline compatibility.
- `Coleza\Domain\Providers\Cpanel\CpanelApiClient`:
  - Formats WHM API 1 authentication headers:
    - API Token: `Authorization: whm <user>:<token>`
    - Access Hash: `Authorization: WHM <user>:<hash>`
    - Password: `Authorization: Basic <base64>`
  - Handles WHM API 1 response envelope (`metadata.result == 1` vs `metadata.result == 0`) and legacy arrays.
  - Translates WHM error conditions (HTTP 401/403, connection errors, function errors) into `ProviderException` mapped to standard `ProvisioningErrorCategory` classifications (`AUTHENTICATION`, `TRANSIENT_NETWORK`, etc.).
  - Methods: `testAuthentication()`, `getSystemLoad()`, `getVersion()`, `listPackagesRaw()`, `call()`.
- `Coleza\Domain\Providers\Cpanel\CpanelPackageDto`:
  - Parses WHM `listpkgs` attributes into typed model (`quotaMb`, `bandwidthMb`, `maxFtp`, `maxSql`, `maxPop`, `maxSub`, `maxPark`, `maxAddon`, `cgiAccess`, `shellAccess`, `dedicatedIp`, `cpanelTheme`, `featureList`).
  - Handles WHM unlimited quota representations (`"unlimited"` / `0`).
- `Coleza\Domain\Providers\Cpanel\CpanelPackageService`:
  - Discovers and lists remote packages.
  - `resolvePackage()`: Robust package matching supporting exact match, case-insensitivity, and reseller username prefix stripping.
  - `validatePackageCompatibility()`: Validates remote package quota and dedicated IP against product/order requirements.
- `Coleza\Domain\Providers\Cpanel\CpanelServerHealthChecker`:
  - Implements `ServerHealthCheckerInterface`.
  - Queries WHM `version` and `systemloadavg`, verifying connectivity, latency, and server 1m/5m/15m load averages against critical threshold (25.0).
  - Produces standard `ServerHealthResult`.
- `Coleza\Domain\Providers\Cpanel\CpanelProvider`:
  - Extends `AbstractProvider` with slug `cpanel`, name `cPanel & WHM`.
  - Registers 9 capabilities: `CREATE_ACCOUNT`, `SUSPEND_ACCOUNT`, `UNSUSPEND_ACCOUNT`, `TERMINATE_ACCOUNT`, `CHANGE_PACKAGE`, `CHANGE_PASSWORD`, `USAGE_METRICS`, `SINGLE_SIGN_ON`, `CUSTOM_ACTION`.
  - Exposes `testAuthentication()`, `listPackages()`, `checkHealth()`, and client factory.
