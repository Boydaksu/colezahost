  - Added `editQuota(string $username, int $quotaMb)` calling WHM `editquota` for custom disk limit adjustments.
  - Added `limitBandwidth(string $username, int $bwlimitMb)` calling WHM `limitbw` for bandwidth quota adjustments.
- `Coleza\Domain\Providers\Cpanel\CpanelProvider`:
  - Concrete implementation of `changePackage(ChangePackageOperation $operation)`:
    - Verifies server connection configuration, returning `MISSING_SERVER_CONNECTION` if missing.
    - Resolves target package through `CpanelPackageService` with tolerance for case and reseller prefixes.
    - Inspects current account plan via `getAccountSummary()`. If the user is already on the requested package and no custom quota overrides are requested, returns idempotent success without unnecessary WHM calls.
    - Dispatches package upgrade/downgrade to WHM.
    - Handles WHM "already on package" responses as idempotent successes.
    - Applies custom resource quotas (`disk_limit_mb`, `bandwidth_limit_mb`) via dedicated WHM quota adjustment endpoints when specified in the operation.
    - Robust error classification via `ProvisioningErrorClassifier` with admin actionable diagnostics on failures.
