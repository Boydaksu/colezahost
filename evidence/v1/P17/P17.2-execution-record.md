## 1. Scope and Objective
Implement Fresh-Install Migration Mode allowing an operator during the Web Installer wizard to optionally select legacy system migration (e.g., WHMCS) directly prior to installer finalization. Ensures that fresh core schema initialization, preflight source scanner checks, dry-run simulation, and live data ingestion execute under an active global migration hold and notification suppression envelope before locking the installation.

## 2. Artifacts Created & Modified
1. `src/Domain/Installer/InstallationMode.php`:
   - Enum distinguishing `FRESH` (clean blank install) from `MIGRATION` (fresh install + legacy import).
2. `src/Domain/Installer/InstallationStep.php`:
   - Added `MIGRATION` step state between `CRON` and `COMPLETED`.
3. `src/Domain/Installer/FreshInstallMigrationConfig.php`:
   - Strong DTO encapsulating source type, database connection parameters, auto-hold setting, notification suppression flags, and conflict resolution strategy.
4. `src/Domain/Installer/FreshInstallMigrationResult.php`:
   - Strong report DTO containing migration success status, migrated count, conflicts count, quarantined count, migration hold status, and full domain summary breakdown.
5. `src/Domain/Installer/FreshInstallMigrationModeService.php`:
   - Validates legacy source database reachability and version compatibility via `WhmcsSourceScanner`.
   - Coordinates live execution via `MigrationExecutionOrchestrator` under an unbroken global hold.
6. `src/Domain/Installer/WebInstallerService.php`:
   - Integrated `executeMigrationStep()` into the installer state machine, transitioning state safely and saving migration metrics into installer summary and lock file.
7. `src/Domain/Installer/DatabaseSetupService.php`:
   - Updated core users and organizations schema compatibility (`name`, `is_active`, `owner_user_id`, `organization_members`).
8. `tests/Unit/Installer/FreshInstallMigrationModeTest.php`:
   - 4 unit tests covering mode enum, invalid source rejection, end-to-end fresh install migration with global hold, and unconfigured orchestrator exception handling.
