## 1. Scope and Objective
Implement comprehensive enterprise backup subsystem:
1. Multi-scope archiving: Full (Database + Files), Database-only, and Files-only.
2. Multi-destination storage adapters: Local filesystem, Remote SFTP, and AWS S3 object storage.
3. Authenticated AES-256-GCM symmetric encryption & decryption with 12-byte cryptographic nonce and 16-byte authentication tag.
4. Tamper-evident `BackupManifest` with comprehensive SHA-256 integrity hash verification.
5. Automated retention policy enforcement (maximum backups count and age threshold pruning).
