## 1. Scope and Objective
Implement comprehensive system operational modes:
1. `NORMAL`: Standard operational mode permitting read-write access and background automation for all users.
2. `SAFE`: Disables non-essential background schedulers and third-party hooks while allowing core read-write transactions.
3. `RECOVERY`: Emergency disaster recovery mode disabling all customer access while allowing super-admin emergency intervention.
4. `READ_ONLY`: Allows catalog browsing, invoice viewing, and ticketing lookups while strictly blocking all database mutations and state changes.
5. `FULL_MAINTENANCE`: Complete maintenance window blocking customer and general traffic with IP whitelist and super-admin bypass support.
