## 1. Subphase Scope & Objective
Establish a production-ready, security-hardened Web Installer wizard covering host environment verification, database setup, administrator bootstrapping, localization, branding, email delivery, and background automation:
- **System Requirements & Pre-flight Checker (`SystemRequirementItem`, `SystemRequirementsReport`, `EnvironmentRequirementChecker`):**
  - Evaluates PHP runtime version (>= 8.2 required, 8.4 recommended).
  - Verifies mandatory extensions: `pdo`, `mbstring`, `openssl`, `json`, `intl`, `curl`, `xml`, `fileinfo`, and database drivers (`pdo_mysql` / `pdo_sqlite`).
  - Verifies recommended graphics extensions (`gd` / `imagick`) for logo processing.
  - Verifies writable directory permissions: `storage/`, `config/`, `logs/`.
  - Verifies PHP memory limit (>= 128MB).
  - Enforces fail-fast installation gates when any mandatory prerequisite fails.
- **Database Connection & Schema Bootstrapping (`DatabaseConfig`, `ConnectionTestResult`, `DatabaseSetupService`):**
  - Parameterized database configuration (host, port, database, username, password, prefix, charset `utf8mb4`, collation).
  - Non-destructive connection testing returning server engine version and connection status.
  - Idempotent schema initialization establishing core baseline tables: `users`, `roles`, `user_roles`, `organizations`, `brands`, `system_settings`, and `cron_runs`.
  - Automatically seeds default `super_admin` role with global permissions `['*']`.
- **Administrator Bootstrapping (`AdminSetupDto`, `AdminBootstrapService`):**
  - Bootstraps root owner account with email validation and strict password complexity policy (>= 10 characters with mixed-case, digits, and symbols).
  - Hashes passwords using secure bcrypt algorithms (`PASSWORD_BCRYPT`).
  - Assigns `super_admin` role and verifies email activation.
- **Regional Localization & Operational Currency Setup (`LocaleSetupDto`, `LocaleSetupService`):**
  - Configures default system locale (`en` or `tr`).
  - Validates timezone against official IANA identifiers (`Europe/Istanbul`, `UTC`, etc.).
  - Configures base operational currency (`USD`, `EUR`, `TRY`, `GBP`) and date formatting standards.
  - Persists settings in `system_settings` table.
- **Active Brand & Organization Identity Setup (`BrandSetupDto`, `BrandSetupService`):**
  - Bootstraps primary organization and active single-tenant brand profile in `brands` and `organizations` tables.
  - Records company legal name, brand display name, support email, company address, and tax registration ID.
- **Outbound Email Transport Configuration (`EmailTransportConfig`, `EmailSetupService`):**
  - Configures email delivery driver (`smtp`, `sendmail`, `memory`, `log`).
  - Stores SMTP parameters (host, port, encryption TLS/SSL, credentials) with encrypted password storage.
  - Provides integrated live delivery test (`sendTestEmail()`) verifying mail dispatch before finalizing setup.
- **Background Automation Scheduler & Cron Setup (`CronSetupService`):**
  - Generates cryptographically secure 64-character cron authentication token (`bin2hex(random_bytes(32))`).
  - Generates ready-to-use crontab CLI execution snippet: `* * * * * php /path/to/bin/coleza schedule:run > /dev/null 2>&1`.
  - Generates secure webhook ping URL: `https://domain.com/api/cron/run?token=XYZ`.
  - Provides token validation and execution logging in `cron_runs` table.
- **Installation Wizard State Machine & Re-entry Lock (`InstallerLock`, `InstallationStep`, `InstallationSummary`, `WebInstallerService`):**
  - Manages sequential 7-step wizard pipeline: `REQUIREMENTS` -> `DATABASE` -> `ADMIN` -> `LOCALIZATION` -> `BRAND` -> `EMAIL` -> `CRON` -> `COMPLETED`.
  - Writes tamper-evident installation lock file (`installed.lock`) containing SHA-256 integrity hash, installation timestamp, app version, and admin email.
  - Prevents installer re-entry attacks: Any future installer call throws `InstallationLockedException::alreadyInstalled()`.
