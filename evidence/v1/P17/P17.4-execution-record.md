## 1. Scope and Objective
Implement mandatory verified pre-update backup workflow:
1. Automated full database dump (schema & table rows) and critical application file archiving into a standalone `.zip` archive.
2. Generation of a tamper-evident `BackupManifest` containing overall archive size, creation timestamp, target upgrade version, and file-by-file SHA-256 integrity checksums.
3. Mandatory post-creation readback verification (`verifyBackup`) checking existence, uncompromised SHA-256 match, and ZIP format integrity.
4. Hard enforcement in `StagedUpdateService::applyValidatedUpdate`: an update is strictly forbidden to proceed unless a verified pre-update backup is generated and validated.
