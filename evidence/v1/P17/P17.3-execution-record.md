## 1. Scope and Objective
Implement secure staged software update mechanism enforcing:
1. Asymmetric cryptographic package signing and verification (Ed25519 Libsodium & RSA fallback).
2. Exact SHA-256 file checksum verification across all staged payload files.
3. Preflight module compatibility checking for all installed and active extensions against target core version and explicit module version prerequisites.
4. Core minimum version prerequisite enforcement.
5. Atomic staged-to-production file application.

---

## 2. Artifacts Created & Modified
1. `src/Domain/Updater/UpdatePackageManifest.php`:
   - Strong manifest DTO encapsulating target version, minimum required current version, release notes, SHA256 file checksums map, required modules map, ordered database migrations, and release timestamp.
2. `src/Domain/Updater/PackageSignatureVerifier.php`:
   - Detached digital signature verification supporting modern Libsodium Ed25519 (`sodium_crypto_sign_verify_detached`) with OpenSSL RSA-SHA256 compatibility.
3. `src/Domain/Updater/ModuleCompatibilityChecker.php`:
   - Inspects installed and active modules from `installed_modules` table against target core version (`min_core_version`, `max_core_version`) and package prerequisites.
4. `src/Domain/Updater/StagedUpdateReport.php`:
   - Comprehensive validation report DTO with status of signature, checksums, module compatibility, failed checksum files list, and incompatible module diagnostics.
5. `src/Domain/Updater/StagedUpdateService.php`:
   - Master updater orchestrator handling isolated staging inspection, tamper detection, hash validation, module checks, and atomic deployment.
6. `tests/Unit/Updater/StagedUpdateAndCompatibilityTest.php`:
   - 5 comprehensive unit tests verifying valid signed update application, tampered manifest rejection, file checksum mismatch detection, incompatible module blocking, and atomic file copy deployment.
