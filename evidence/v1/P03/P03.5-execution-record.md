## 1. Components Implemented
- `Coleza\Domain\Identity\Audit\AuditLogger`: Dedicated security audit log service writing immutable event records (`security_audit_logs` table) separate from general application logs (tracking `actor_user_id`, `impersonator_user_id`, `event_type`, `target_resource`, IP, and user-agent).
- `Coleza\Domain\Identity\Impersonation\ImpersonationService`:
  - Enforces `users.impersonate` RBAC permission check before initiating session takeover.
  - Prohibits self-impersonation and nested impersonations.
  - Stores audit entries on start and stop of impersonation sessions.
  - Enforces high-risk operational barrier (`BLOCKED_HIGH_RISK_OPERATIONS` preventing password change, 2FA removal, secret retrieval, and account deletion while impersonating).
- `CoreServiceProvider`: Registered `AuditLogger` and `ImpersonationService` singletons.
