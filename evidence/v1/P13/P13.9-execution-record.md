## 1. Subphase Scope & Objective
Execute comprehensive end-to-end integration and golden path verification covering all P13 components working seamlessly together:
1. **Department Setup & Agent Membership:** Provision departments (Technical Support, Billing Desk) and assign multi-tier agents.
2. **SLA Policy Definition:** Define strict first-response (60m) and resolution (240m) SLA policies linked to technical tickets.
3. **Multi-Tenant Ticket Creation:** Client user opens ticket with high priority, department linkage, and relational context to active VPS service.
4. **Relational Context Verification:** Read and summarize contextual linked entity data (service IP, package, status) via decoupled provider.
5. **Round-Robin Assignment:** Automated balanced assignment to available technical agent with audit logging.
6. **Agent Reply & SLA Response Clock:** Agent replies via canned response interpolation; first-response SLA is closed cleanly without breach.
7. **Secure Attachment Upload & Validation:** Secure attachment upload verified with SHA-256 hash, MIME filtering, and private isolation.
8. **Internal Team Notes:** Internal staff collaboration note added without leaking to client conversation thread.
9. **Contextual Action Execution:** Executing approved context action (`restart_service`) via decoupled command bridge.
10. **Organization Role & Access Enforcement:** Granular verification of `assertCanView` / `assertCanReply` for direct client vs organization members with/without `org.tickets.all` permissions. Cross-org isolation strictly blocked.
11. **Resolution, SLA Closure & Reopen Prevention:** Staff resolves ticket; client reopens with query; final resolution satisfies overall resolution SLA.
12. **Broadcasting Platform Announcements:** Announcement creation with pinned order and public vs authenticated filtering.
