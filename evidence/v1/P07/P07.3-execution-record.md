## 1. Components Implemented
- `Coleza\Domain\Finance\Profitability\GatewaySettlement`: Gateway settlement payout entity with sequential batch identifiers (`SETTLE-YYYYMMDD-XXXXXX`), capturing gateway codes, payout timestamps, gross processing totals, deducted gateway processing fees, net settlement amounts, destination accounts, and reference IDs.
- `Coleza\Domain\Finance\Profitability\ProfitabilityReport`: Multi-dimensional profitability reporting value object delivering period-based revenue, expense totals, gross gateway fees, net operating income, profit margins, and currency breakdown models.
- `Coleza\Domain\Finance\Profitability\ProfitabilityService`: Financial intelligence engine coordinating:
  - Atomic inter-account gateway settlement batching (`recordGatewaySettlement`), debiting gross processing funds from virtual gateway accounts, logging gateway transaction fee deductions, and depositing net funds into target business bank accounts.
  - Periodic profitability calculation (`generateProfitabilityReport`), aggregating total paid invoice revenues, operating expenditures, and transaction processing fees.
