## 1. Components Implemented
- `Coleza\Domain\Providers\Contracts\ProviderCapability`: Standard capability flags (`CREATE_ACCOUNT`, `SUSPEND_ACCOUNT`, `UNSUSPEND_ACCOUNT`, `TERMINATE_ACCOUNT`, `CHANGE_PACKAGE`, `CHANGE_PASSWORD`, `USAGE_METRICS`, `SINGLE_SIGN_ON`, `CUSTOM_ACTION`) and capability validation.
- `Coleza\Domain\Providers\Contracts\ProviderCapabilitySet`: Immutable value object managing supported capability sets, immutable addition/removal, capability checks (`supports()`), and exception assertions.
- `Coleza\Domain\Providers\Exceptions\ProviderException`: Base exception capturing structured error codes and contextual arrays.
- `Coleza\Domain\Providers\Exceptions\UnsupportedCapabilityException`: Exception raised when an operation is dispatched to a provider lacking support for that capability.
- `Coleza\Domain\Providers\DTO\ServerConnectionDto`: Secure server connection model supporting hostname, IP, port, SSL, authentication types, and credential masking (`getMaskedSecret()`, `toSafeArray()`).
- `Coleza\Domain\Providers\DTO\ProviderOperationResult`: Unified result value object with named factories (`success()`, `failure()`), operation type, message, external IDs, error codes, and audit timestamps.
- **Provider Operation DTOs** (`Coleza\Domain\Providers\Operations\`):
  - `OperationInterface`: Standard contract implemented by all provider operations.
  - `CreateAccountOperation`: Captures username, password (masked in serialization), domain, package ID, resource quotas, and server connection.
  - `SuspendAccountOperation`: Captures username, suspension reason, server, and metadata.
  - `UnsuspendAccountOperation`: Captures username, server, and metadata.
  - `TerminateAccountOperation`: Captures username, backup retention flag (`keepBackup`), server, and metadata.
  - `ChangePackageOperation`: Captures username, new package identifier, updated resource quotas, and server.
  - `ChangePasswordOperation`: Captures username, new password (masked in serialization), and server.
  - `UsageMetricsOperation`: Captures username, server, and metadata for quota/bandwidth polling.
  - `SingleSignOnOperation`: Captures username, client IP, server, and metadata for SSO token generation.
  - `CustomActionOperation`: Dynamic action DTO for provider-specific actions with arbitrary parameter payloads.
- `Coleza\Domain\Providers\Contracts\ProviderInterface`: Formal hosting provider contract exposing metadata, capability set, and all operation execution methods.
- `Coleza\Domain\Providers\Contracts\AbstractProvider`: Base provider implementation providing default assertions and template methods.
- `Coleza\Domain\Providers\Registry\ProviderRegistry`: Central registry managing active providers, slug lookups, capability querying (`getByCapability()`), and capability assertions.
- `Coleza\Domain\Providers\Testing\MockHostingProvider`: Reusable test double provider supporting recorded operation inspection, custom capabilities, and canned responses.
