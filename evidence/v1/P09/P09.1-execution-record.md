## 1. Components Implemented
- `Coleza\Domain\Commerce\Services\ServicePlacement`: Service placement entity modeling server, server pool, location relations, placement statuses (`unassigned`, `reserved`, `placed`, `migrating`, `evicted`), hostname/dedicated IP assignments, package identifier, disk/bandwidth limits, and arbitrary resource quotas.
- `Coleza\Domain\Commerce\Services\ServiceBillingRelation`: Encapsulates recurring billing properties, auto-renewal flag, invoice lead generation date calculations, overdue determination, grace period days, and suspension/termination thresholds.
- `Coleza\Domain\Commerce\Services\ServiceCancellationRequest`: Lifecycle cancellation request entity managing immediate vs end-of-period cancellations, request reasons, processing timestamps, and request statuses (`pending`, `processed`, `revoked`).
- `Coleza\Domain\Commerce\Services\Service`: Updated core Service aggregate root to hold active `placement`, `billingRelation`, and `cancellationRequest`, exposing lifecycle status accessors and serialization.
- `Coleza\Domain\Commerce\Services\ServiceService`:
  - Added table migrations for `service_placements` and `service_cancellations`, and schema additions to `services` (`auto_renew`, `grace_period_days`, `termination_grace_period_days`).
  - Added placement management: `assignPlacement`, `releasePlacement`, `getPlacementForService`.
  - Added cancellation handling: `requestCancellation` (immediate vs end-of-period), `revokeCancellation`, `getCancellationForService`, `processDueCancellations`.
  - Added automated billing evaluation and lifecycle enforcement: `evaluateBillingLifecycle`, `processOverdueServices` (automatic suspension and eviction/termination).
  - Hydrated services with placement, billing relation, and cancellation request records.
