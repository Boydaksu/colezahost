## 1. Components Implemented
- `Coleza\Domain\Commerce\Payments\Exceptions\PaymentRefundFailedException`: Specific domain exception capturing failed refund attempt context (paymentId, amountMinor, gateway errorCode, raw gateway details).
- `Coleza\Domain\Commerce\Payments\RefundAttempt`: Audit entity modeling gateway refund attempts (`success` vs `failed`), retaining gateway error codes, reasons, and timestamps.
- `Coleza\Domain\Commerce\Payments\Gateways\PaymentWebhookResult`: Immutable result value object delivering outcome states (`processed`, `duplicate`, `failed`, `already_completed`) and associated payment identifiers.
- `Coleza\Domain\Commerce\Payments\Gateways\PaymentWebhookEvent`: Inbound event entity logging raw payload hashes (`SHA-256`), gateway identifiers, event keys, status, and associated payment IDs.
- `Coleza\Domain\Commerce\Payments\Gateways\PaymentWebhookHandler`: Inbound webhook & callback processor providing:
  - Strict event idempotency checking via `payment_webhook_events`. Replayed / retried webhooks return `duplicate` without re-crediting or touching invoice/order state.
  - Gateway verification dispatch (`verifyPayment`) resolving token status.
  - Automatic payment completion, gateway commission fee attribution, invoice allocation (`applyPayment`), and order activation (`transitionOrderStatus` to `active`).
  - Out-of-order callback detection when payment was already settled.
  - Verification failure mitigation marking pending payments as `failed`.
- Enhanced `Coleza\Domain\Commerce\Payments\PaymentService`:
  - Added `payment_refund_attempts` and `payment_webhook_events` schema management in `ensureTables()`.
  - Added `refundViaGateway(...)` featuring atomic failure protection: gateway rejections record failed audit attempts and throw `PaymentRefundFailedException` while preserving payment status and refundable balances 100% intact.
  - Added `recordRefundAttempt(...)` and `listRefundAttemptsForPayment(...)`.
  - Added `completePaymentFromGateway(...)` and `failPaymentFromGateway(...)`.
  - Added `findPaymentByToken(...)`.
