## 1. Components Implemented
- `Coleza\Domain\Notifications\Channel\NotificationChannel`: Communication medium enum (`EMAIL`, `IN_APP`, `SMS`, `WEBHOOK`).
- `Coleza\Domain\Notifications\Channel\NotificationPriority`: Dispatch priority enum (`LOW`, `NORMAL`, `HIGH`, `URGENT`).
- `Coleza\Domain\Notifications\Messages\NotificationMessage`: Comprehensive envelope capturing recipient, locale (`tr`/`en`), HTML/plain-text bodies, channel, priority, sender overrides, and metadata.
- `Coleza\Domain\Notifications\Delivery\DeliveryResult`: Structured outcome object recording message IDs, transport drivers, error descriptions, and ISO8601 delivery timestamps.
- `Coleza\Domain\Notifications\Transport\MailerInterface`: Transport abstraction contract for message dispatch.
- `Coleza\Domain\Notifications\Transport\SmtpConfiguration`: Secure SMTP credentials model enforcing strict secret masking (`getMaskedPassword()`, `toSafeArray()`) to protect mail credentials.
- `Coleza\Domain\Notifications\Transport\MemoryMailTransport`: In-memory test double transport allowing inspection, verification, and simulated transport failures.
- `Coleza\Domain\Notifications\Transport\SmtpTransport`: Pure PHP socket mailer supporting `STARTTLS`, `AUTH LOGIN`, RFC-compliant multipart/alternative MIME assembly with base64 encoding and UTF-8 subject formatting.
- `Coleza\Domain\Notifications\Templates\NotificationTemplateEngine`: Multi-lingual template compiler supporting Turkish and English core business events (`order_created`, `invoice_created`, `payment_received`, `service_activated`, `service_suspended`, `password_reset`), responsive email layout wrapper, and strict XSS variable escaping.
- `Coleza\Domain\Notifications\NotificationEngine`: Central notification orchestrator compiling localized templates and dispatching via configured transports.
