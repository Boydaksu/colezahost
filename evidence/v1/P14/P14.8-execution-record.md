## 1. Subphase Scope & Objective
Implement Privacy Tombstones and backup restore reconciliation fulfilling the Data Constitution rule and Golden Scenario G08:
- **Data Constitution (`03-constitution/DATA_CONSTITUTION.md`):**
  - "Backup restore reapplies Privacy Tombstones before production opens."
- **Golden Scenario G08 (`05-testing/GOLDEN_SCENARIOS.md`):**
  - "G08 Privacy Restore: Backup user → Erase → Restore old backup → Apply tombstone → PII must not resurrect."
- **Disaster Recovery Runbook (`10-release/DISASTER_RECOVERY_RUNBOOK.md`):**
  - Step 6: "Apply schema compatibility/migrations and Privacy Tombstones."
  - Step 10: "Open read-only then production mode; record DR evidence."

### Architectural Components:
1. **`PrivacyTombstone` Entity:**
   - Captures subject user ID, blind email HMAC-SHA256 hash (`user_email_hash`), erasure type (`ANONYMIZE`, `DELETE`, `PURGE`), reason, erasure log checksum, serialized audit metadata, timestamp, and tamper-evident HMAC signature (`integrity_signature`).
   - Supports cryptographic integrity validation (`verifyIntegrity`) and email match detection without storing plaintext PII.
2. **`TombstoneStoreInterface` & `FileTombstoneStore`:**
   - Out-of-band persistent storage independent of the operational database.
   - Guarantees tombstones survive catastrophic database wipes and older backup restores.
   - Provides manifest export and import capabilities with tamper-evident checksums.
3. **`PrivacyTombstoneService`:**
   - Manages relational database `privacy_tombstones` table and two-way synchronization with out-of-band persistent storage.
   - Queries tombstoned user IDs and emails (`isTombstoned`, `isEmailTombstoned`).
4. **`PrivacyErasureService` Integration:**
   - Injected with `PrivacyTombstoneService`.
   - Automatically records an immutable privacy tombstone upon every successful erasure execution.
5. **`BackupRestoreReconciliationService` & `RestoreReconciliationReport`:**
   - Scans restored database against authoritative persistent tombstones.
   - Detects resurrected users (by User ID or blind email hash) whose PII was revived by a restored historical database backup.
   - Automatically re-applies anonymization and wipes resurrected consents (`DELETE FROM privacy_consents`).
   - Produces a tamper-evident `RestoreReconciliationReport`.
   - Enforces the **Production Gate** (`assertProductionReady`): blocks lifting the production seal if any unscrubbed resurrected PII remains.
