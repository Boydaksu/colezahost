## 1. Subphase Scope & Objective
Establish a strictly read-only WHMCS database connector, version and capability scanner, and preflight inspection engine:
- **Strict Read-Only Enforcement (`WhmcsReadOnlyConnector`):**
  - Architecture and Data Constitution compliance: mutations, drops, truncates, creates, and alters on the source database are strictly forbidden.
  - Query inspection blocks any SQL containing `INSERT`, `UPDATE`, `DELETE`, `DROP`, `ALTER`, `TRUNCATE`, `REPLACE`, `CREATE`, throwing `ValidationException`.
  - Only safe read queries (`SELECT`, `SHOW`, `EXPLAIN`, `PRAGMA`) are permitted.
- **WHMCS Version & Environment Detector (`WhmcsVersionInfo`):**
  - Semantic version parsing: major, minor, patch, and build identifiers.
  - Architectural capability flags: detects WHMCS v8+ multi-user accounts architecture (`tblusers`, `tblusers_clients`) vs legacy v7 single-login clients.
- **Schema & Capability Scanner (`WhmcsSourceScanner`, `WhmcsCapabilityProfile`):**
  - Table inventory: verifies existence and counts records across all 17 core WHMCS tables (`tblclients`, `tblproducts`, `tblhosting`, `tbldomains`, `tblinvoices`, `tblaccounts`, `tbltickets`, etc.).
  - Automated module discovery: extracts active server modules (e.g. `cpanel`, `plesk`, `directadmin`), registrar providers (e.g. `enom`, `namesilo`), and payment gateways (e.g. `stripe`, `paypal`).
  - Compatibility verification: evaluates missing tables and version support thresholds.
- **Preflight Inspection & Integrity Scanner (`WhmcsPreflightService`, `WhmcsPreflightReport`):**
  - Validates read-only connectivity.
  - Relational orphan detection: detects services, domains, and invoices referencing non-existent clients.
  - Summarizes total estimated migration entities across the source database.
  - Emits overall preflight readiness classification (`READY`, `READY_WITH_WARNINGS`, `INCOMPATIBLE`).
