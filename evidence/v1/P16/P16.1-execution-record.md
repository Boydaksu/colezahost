## 1. Subphase Scope & Objective
Establish the foundational generic migration architecture, staging repository, canonical DTO models, mapping engine, and validation engine enforcing the core Data Constitution mandate:
**Migration guarantees Zero Silent Data Loss; every source record gets a terminal accounting state.**

- **Staging Lifecycle & Terminal Accounting (`StagingRecord`, `StagingRecordStatus`, `StagingAccountingReport`):**
  - Staging record states: `STAGED`, `VALIDATED`, `TRANSFORMED`, `MIGRATED`, `QUARANTINED`, `SKIPPED_UNSUPPORTED`, `FAILED`.
  - Terminal statuses guaranteed: `MIGRATED`, `QUARANTINED`, `SKIPPED_UNSUPPORTED`, `FAILED`.
  - Immutable preservation of the original pristine `raw_payload_json` to ensure no source data is lost.
  - Zero Silent Loss verification formula:
    `unaccounted_diff = total_staged - (migrated + quarantined + skipped + failed + in_flight) === 0`.
- **Database Staging Repository (`DatabaseStagingRepository`, `StagingRepositoryInterface`):**
  - Manages `migration_staging_records` table with batch indexing, unique constraints, and status rollups.
  - Generates comprehensive accounting reports auditing terminal state reconciliation.
- **Canonical DTO Layer (`CanonicalEntityInterface`):**
  - Fully decouples legacy source engines (WHMCS, Blesta, CSV) from Coleza Core domain models.
  - Standardized representations:
    - `CanonicalClientDto`: personal info, company, contact details, currency, tax exemption, custom fields.
    - `CanonicalProductDto`: plan name, hosting type, pricing, billing cycle, provisioning module.
    - `CanonicalServiceDto`: client reference, product reference, domain, credentials, recurring price, cycle.
    - `CanonicalDomainDto`: client reference, domain name, registrar, expiry, next due date, autorenew, ID protection.
    - `CanonicalInvoiceDto`: invoice number, subtotal, tax, total, status, dates, line items.
    - `CanonicalPaymentDto`: client reference, invoice reference, amount, gateway, fee, transaction ID.
    - `CanonicalTicketDto`: department, subject, message, priority, status, mask, thread replies.
- **Generic Mapping Engine (`GenericMappingEngine`, `MappingEngineInterface`):**
  - Converts source payloads into canonical DTOs.
  - Preserves any unmapped source properties into `metadata['unsupported_source_fields']` guaranteeing zero silent drops.
- **Canonical Validation Engine (`CanonicalValidationEngine`, `ValidationResult`):**
  - Pre-import validation preventing corrupt data from ever entering Core domain tables.
  - Validates RFC email syntax, non-negative prices, valid domain names, invoice arithmetic (`total == subtotal + tax`), and positive payment sums.
  - Invalids are safely directed to `QUARANTINED` with exact error lists.
- **Staging Pipeline Coordinator (`StagingPipelineService`):**
  - Orchestrates batch ingestion, transformation, validation, and zero-loss accounting reporting.
