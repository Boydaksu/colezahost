## 1. Subphase Scope & Objective
Implement the core entity migration engine from WHMCS to Coleza Host with strict Zero Silent Data Loss certification:
- **Core Entity Extraction (`WhmcsCoreEntityExtractor`):**
  - Read-only extraction across `tblclients`, `tblcontacts`, `tblproducts`, `tblproductgroups`, `tblpricing`, `tblhosting`, `tbldomains`, and `tblcustomfields`.
  - Currency resolution mapping currency IDs to ISO-4217 standard currency codes.
  - Multi-tier product pricing join (`tblpricing` -> `tblproducts`).
  - Custom fields resolution (`tblcustomfields` / `tblcustomfieldsvalues`).
- **Core Entity Migrator (`WhmcsCoreEntityMigrator`):**
  - **Clients & Organizations:**
    - Raw WHMCS clients ingested into staging (`StagingRecordStatus::STAGED`).
    - Validated through `CanonicalValidationEngine`.
    - Migrated into Coleza `users` and linked to `organizations` if company name is present.
    - Subaccounts (`tblcontacts` with `subaccount=1`) migrated and linked to parent client organizations.
    - User ID mapped in `ProviderIdentityResolver`.
  - **Product Groups & Products:**
    - Product groups created in Coleza catalog (`product_groups` table).
    - Products migrated with recurring pricing, module configuration, and package name into `products` table.
    - Product ID mapped in `ProviderIdentityResolver`.
  - **Services (Hosting Accounts):**
    - Services validated and adopted via `ServiceAdoptionService`.
    - Non-destructive execution: provisioning suppressed (`is_adopted = 1`, `provisioning_suppressed = true`), preventing accidental remote cPanel/Plesk triggers.
    - Foreign keys resolved: linked to migrated user and product.
    - Adopted provider identity recorded in `adopted_provider_identities`.
  - **Domains:**
    - Domains validated and adopted via `DomainAdoptionService`.
    - Non-destructive execution: registrar API calls suppressed (`is_adopted = 1`, `registrar_api_suppressed = true`), preventing duplicate registration charges.
    - Linked to migrated user and registered in `adopted_provider_identities`.
- **Zero Silent Data Loss Certification (`WhmcsCoreEntityMigrationResult`):**
  - Every source record staged reaches a verified terminal state (`MIGRATED` or `QUARANTINED`).
  - Terminal invariant certified: `StagingAccountingReport::getUnaccountedDiff() === 0` and `isFullyTerminal() === true`.
  - Invalid records (e.g., malformed email, invalid domain syntax, orphan service referencing unresolved client) are safely quarantined with exact diagnostics.
