## 1. Subphase Scope & Objective
Establish robust, non-destructive adoption workflows for existing external infrastructure accounts (cPanel, Plesk, DirectAdmin) and registered domains (Enom, NameSilo, ResellerClub):
- **Core Problem & Solution:**
  - Migrating existing services and domains must NEVER trigger normal provisioning or registrar creation workflows (`create_account`, `register_domain`), which would result in errors, duplicate account creation, or registrar charges.
  - Built explicit "Adopt / Takeover" workflows that link internal Coleza records to external infrastructure while strictly suppressing remote creation actions (`suppress_provisioning = true`, `is_adopted = 1`).
- **Provider Identity Links (`AdoptedProviderIdentity`, `AdoptedIdentityType`, `AdoptedIdentityRepository`):**
  - Manages `adopted_provider_identities` table tracking adopted external credentials, server IDs, registrar codes, usernames, and domain references.
  - Guarantees uniqueness per provider and external identifier (`UNIQUE (provider_type, provider_identifier, external_reference_id)`).
- **Identity Resolution (`ProviderIdentityResolver`):**
  - Resolves source server keys to Coleza target server IDs.
  - Resolves source registrar codes to Coleza registrar providers.
  - Resolves source product and client IDs to Coleza catalog and user entities.
- **Service Adoption Engine (`ServiceAdoptionService`, `ServiceAdoptionResult`):**
  - Adopts `CanonicalServiceDto` into `services` table with status intact (`active`, `suspended`).
  - Idempotent re-runs: re-adopting the same source service returns existing record without duplicate creation.
  - Conflict detection: prevents two different source entities from adopting the same server username.
  - Optional read-only server verification via `RemoteIdentityVerifierInterface`.
- **Domain Adoption Engine (`DomainAdoptionService`, `DomainAdoptionResult`):**
  - Adopts `CanonicalDomainDto` into `domains` table with registration dates, expiry dates, next due dates, and nameservers.
  - Suppresses registrar API registration calls.
  - Enforces domain name conflict checks across source entities.
