## 1. Subphase Scope & Objective
Establish robust execution controls, simulation preview, collision handling, quarantine triage, interrupted session resumption, and absolute idempotency:
- **Dry-Run Simulation Engine (`DryRunReport`, `MigrationExecutionOrchestrator::executeDryRun`):**
  - Non-destructive execution across all entities (clients, products, services, domains, invoices, payments, credits, support).
  - Validates extraction, mapping, schema constraints, and orphan links without mutating production tables (verified 0 records inserted into `users`, `services`, `domains`, `invoices`, `payments`).
  - Projects migration counts, quarantines, potential conflicts, and multi-currency ledger totals.
- **Pre-Flight Conflict Detector (`ConflictDetector`, `ConflictResolutionStrategy`):**
  - Scans for user email collisions, domain registration collisions, hosting account server/username collisions, invoice number collisions, and product slug collisions.
  - Formulates actionable collision reports to prevent unique constraint failures.
- **Quarantine Manager & Remediation (`QuarantineManager`):**
  - Quarantines invalid records (malformed emails, syntax errors, missing foreign key references) with complete diagnostic errors.
  - Summarizes quarantine reasons by entity type.
  - Provides `remediate()` workflow to apply corrected field overrides and re-evaluate records to `VALIDATED` status.
- **Checkpoint & Resume Engine (`MigrationCheckpoint`, `MigrationCheckpointRepository`):**
  - Tracks migration batch progress step-by-step (`clients` -> `products` -> `services` -> `domains` -> `invoices` -> `payments` -> `credits` -> `support` -> `completed`).
  - Persists checkpoint state into database (`migration_checkpoints`).
  - Automatically resumes interrupted batches from the last successful step without redundant re-processing.
- **Absolute Idempotency Guarantee:**
  - Repeated executions of the live migration pipeline produce zero duplicate users, services, domains, invoices, or payments.
  - Certified Zero Silent Data Loss invariant: `unaccountedDiff === 0` and `inFlightCount === 0`.
