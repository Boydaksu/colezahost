## 1. Objectives & Scope
Certify comprehensive localization completeness and WCAG 2.1 AA accessibility & visual consistency:
1. **TR/EN Dictionary Completeness & Key Parity (LOC-01):** Establish complete, symmetric translation dictionaries for Turkish (`tr_TR`) and English (`en_US`) across all core application domains (auth, two-factor, organizations, impersonation, navigation, common actions, billing, services, domains, tickets, statuses, validation). Guarantee 0 missing keys and 0 mismatched placeholders.
2. **Document & Transactional Localization (LOC-02):** Certify full localization of financial documents, terms, localized money formatting (`1.250,50 TL` vs `$1,250.50`), and date formatting (`09.10.2026` vs `2026-10-09`).
3. **Design System Token WCAG AA Contrast Audit (A11Y-01):** Mathematically audit contrast ratios across design system color tokens (`tokens.css`) for both Light Mode and Dark Mode against WCAG 2.1 AA standard thresholds ($\ge 4.5:1$ for normal text, $\ge 3:1$ for large text/components).
4. **Component & Pattern Accessibility & ARIA Semantics (A11Y-02):** Inspect and audit form controls, status badges (non-color dependent indicators), alerts, modals (`role="dialog"`, `aria-labelledby`), contextual drawers (`role="region"`), and data tables (`scope="col"`, `role="grid"`, `aria-sort`).
5. **Shell Layout Accessibility (A11Y-03):** Verify AdminShell and ClientShell layouts adhere to accessible markup without violations.
