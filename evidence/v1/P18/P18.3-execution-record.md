## 1. Objectives & Scope
Execute an exhaustive multi-dimensional audit of the entire codebase before stable release certification:
1. **Secret & Credential Leak Scan:** Ensure zero hardcoded production private keys, cloud tokens (AWS/GCP), GitHub tokens, or live payment secrets exist in the repository.
2. **Insecure & Dangerous Functions Scan:** Ensure zero occurrences of `eval()`, `create_function()`, `passthru()`, `shell_exec()`, or unapproved system command executions exist in production code (`src/`).
3. **Debug Leaks & Suppression Scan:** Ensure zero occurrences of debug dump calls (`var_dump`, `dd`, `print_r`) or error suppression operators (`@$obj->`) exist in production code.
4. **Architecture & Strict Typing:** Ensure 100% of PHP files in both `src/` and `tests/` enforce `declare(strict_types=1);` and respect clean hexagonal boundaries (Domain does not depend on Infrastructure, Foundation has zero Domain coupling).
5. **Dependency & Shared-Host Compliance:** Verify runtime requirements (`php >= 8.4`), pure PSR production dependencies (`psr/container`, `psr/log`), and zero bloated framework lock-in.
