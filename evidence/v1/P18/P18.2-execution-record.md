## 1. Objectives & Scope
Formally execute, verify, and lock all 8 Golden E2E acceptance scenarios defined in `05-testing/GOLDEN_SCENARIOS.md` before certifying the V1 Stable Release Candidate:
1. **G01 Manual Commerce:** Organization -> Product -> Order -> Invoice -> Manual Payment -> Manual Service (Active).
2. **G02 Automated Hosting:** Client -> Order -> Risk -> Invoice -> iyzico -> Webhook -> Queue -> Placement -> cPanel -> Active -> Welcome Email.
3. **G03 Renewal Lifecycle:** Scheduler -> Renewal Invoice -> Notification -> Payment OR overdue/grace -> Suspend -> Settle -> Reactivate.
4. **G04 Domain Lifecycle:** Availability -> Order -> Payment -> Registrar Register -> Active -> Reminder -> Renewal.
5. **G05 Failure & Idempotency:** Payment succeeds, cPanel timeout/uncertain response, retry/reconcile, zero duplicate remote account.
6. **G06 Disaster Recovery:** Full backup -> intentional broken module/update -> Recovery mode -> Rollback/Restore -> System Doctor Health (7/7 HEALTHY PASS).
7. **G07 WHMCS Cutover:** Scan -> Map -> Dry-run -> Migrate -> Reconcile (0 discrepancy) -> Migration Hold -> Cutover -> Cryptographic Audit Seal.
8. **G08 Privacy Restore:** Backup user -> Erase (GDPR Art. 17) -> Restore old backup -> Reconcile tombstone -> Zero PII resurrection.

## 2. Implementation Summary

### Master E2E Suite (`tests/Integration/Golden/`)
- **`GoldenMasterScenariosE2ETest`**:
  - `testG01ManualCommerceScenario`: Exercises currency/tax pricing, order placement, invoice issuance, bank transfer recording & approval, manual service activation.
  - `testG02AutomatedHostingScenario`: Exercises cPanel node registration, product checkout, iyzico payment callback, server placement calculation, cPanel account creation, active service provisioning, and welcome email delivery.
  - `testG03RenewalLifecycleScenario`: Exercises automated renewal invoice generation (14-day lead time), overdue grace evaluation, automated suspension, payment settlement, and automated unsuspend with due date advancement.
  - `testG04DomainLifecycleScenario`: Exercises NameSilo registrar integration, TLD pricing, domain availability check, idempotent domain registration, ICANN contact mapping, and domain renewal.
  - `testG05FailureAndIdempotencyScenario`: Exercises network timeout error classification (`TRANSIENT_NETWORK`), provisioning retry runner, remote node reconciliation querying account existence, and ghost account duplicate prevention.
  - `testG06RecoveryAndHardeningScenario`: Exercises verified pre-update enterprise backup creation, intentional configuration corrupt injection, emergency `RECOVERY` operational mode transition, `RollbackManager` atomic restore, database restoration, return to `NORMAL` mode, and `SystemDoctorService` 7-component diagnostic (`HEALTHY`).
  - `testG07WhmcsCutoverScenario`: Exercises end-to-end WHMCS data ingestion, table mapping, migration hold engagement, notification suppression interception, cutover checklist evaluation, and cryptographic audit seal generation.
  - `testG08PrivacyTombstoneRestoreScenario`: Exercises GDPR Right to be Forgotten erasure with out-of-band persistent tombstone, legacy database restore, and automated `BackupRestoreReconciliationService` re-scrubbing resurrected users into anonymized placeholders (`[Anonymized User #id]`, `status = erased`).

### Tooling (`tools/`)
- **`tools/run_golden_scenarios.py`**: Automated CLI test runner and status reporter verifying all 8 scenarios with detailed timings and exit code enforcement.
