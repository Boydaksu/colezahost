# Release Family Rules

## While V1 is active
- V1.1/V2+ code implementation is forbidden unless explicitly listed as `V1-FOUNDATION`, and then only the minimum contract/data-model/extension point necessary for a V1 consumer may be written.
- V1.1/V2+ phase files are planning references, never permission to code them early.

## V1.1 entry
P18 Stable must PASS and field issues must be triaged. V1.1 must not redefine V1 financial/security semantics without ADR + migration/compatibility plan.

## V2+ entry
P118 V1.1 release gate must PASS for the canonical sequence. Each V2+ product family requires a fresh product spec and impact assessment; the listed subphases are roadmap boundaries, not automatic scope authorization.
